# Service knowledge quiz

Every question is about **Azure DocumentDB**, Microsoft's managed MongoDB-compatible document database. The questions are chosen because the answer differs between this service and its neighbours, so a wrong answer shows which neighbour the model has in mind.

Add or remove questions freely. Keep the ids stable so results can be compared across runs.

- **Q01** What is the Azure resource provider namespace and resource type of an Azure DocumentDB cluster?
- **Q02** Which Azure CLI command group creates and manages a cluster? Is it in the core CLI or an extension?
- **Q03** Which Bicep and Terraform resource types deploy a cluster?
- **Q04** What does a connection string look like: scheme, host suffix, port, and the options it must carry?
- **Q05** How is capacity provisioned and billed: request units, compute tiers with vCores, serverless, or something else?
- **Q06** Which authentication methods are supported, and how does a driver authenticate with Microsoft Entra ID?
- **Q07** Which client library should an application use? Is there a service-specific SDK?
- **Q08** Which vector index types are supported, and what does the command that creates one look like?
- **Q09** How are full-text search and hybrid search done?
- **Q10** Which MongoDB wire protocol or server versions are supported, and which commonly used MongoDB features are not?
- **Q11** How do you run the database locally for development and tests: which image or emulator, and which port?
- **Q12** Are change streams supported, and does anything have to be enabled first?
- **Q13** Which MCP server gives an agent data-plane tools for this service? Does the general Azure MCP Server cover it?
- **Q14** What was this service called before, and how does it relate to Azure Cosmos DB and to the open-source DocumentDB project?
- **Q15** What engine is underneath, and does that change anything in application code?
